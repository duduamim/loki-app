# Loki

Cliente gratuito para jogar **Dofus Touch** no Windows.

- **Site:** https://duduamim.github.io/loki-app
- **Download:** [última versão](https://github.com/duduamim/loki-app/releases/latest) (`Loki-Setup-….exe`)
- **Código-fonte:** cada versão traz o `Loki-…-source.zip` (GPL-3.0)

Este repositório guarda o site e os downloads do Loki. Loki não é afiliado à Ankama Games; Dofus Touch é marca e propriedade da Ankama Games. Créditos em [NOTICE.md](NOTICE.md).
